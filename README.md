# GDL90



Java implementation of the GDL90 protocol.


This source code is based on the work of **Frank van der Hulst** (drifter.frank@gmail.com). I have adapted it so that it can be used in general Java applications. The compiled JAR files can be used with Java 17 and later. However, the source code should also be compilable under Java 1.8 with just a few minor modifications.



To verify that all libraries and the Orekit data have been successfully integrated, you can run the Tester class.



**Current data for Orekit:** https://gitlab.orekit.org/orekit/orekit-data
